# 芽仔 IP 规范

## 第一身份与媒介锚点

始终以 ../assets/ip/yazai-paper-blue-anchor-v1.png 为第一身份与媒介参考。它同时锁定芽仔造型和“画在同一张暖纸上”的表现方式。

../assets/ip/yazai-canonical-front-v1.png 只用于核验身体比例、按钮位置和身份细节，或在身份漂移时做结构修复；常规生成不要把它作为风格参考，以免引入光滑 3D 塑料质感。其他芽仔图片只能提供动作线索。

## 不可变特征

- 大头短身、短腿、圆手套和圆头靴。
- 白色圆角宇航头盔与身体自然连贯。
- 无五官的深黑圆角面罩，只保留服从曲面与光源的光学反光；不加眼睛、嘴、眉毛或文字。
- 头顶正中一组亮绿色双叶嫩芽。
- 两侧浅灰圆形耳罩。
- 双臂各一圈干净红色臂带，双腿各一圈浅灰腿带。
- 胸前白色控制板：左侧一个大白色方钮，右上一个蓝色圆钮，右下一个红色圆钮。
- 手脚数量正确，动作关系自然。

## 面罩反光

- 面罩必须保留单侧反光来建立曲面和立体感。先根据角色朝向、动作与场景主光源选择一个受光侧，再把所有可见高光限制在这一侧。
- 主反光是面罩上唯一独立的高光形状：一块连续、较宽、边缘柔和的弧形或椭圆形面，沿面罩曲率自然衰减；可以在这块连续形状内部做灰阶过渡，但不能分裂为互不相连的亮点。
- 面罩任何位置都禁止第二高光、辅助闪点、小圆形 catchlight、孤立白点、另一侧亮线、左右成对高光、对称短线或两边各一个亮区；即使真实镜面可能出现辅助反射，也不采用这种设计。
- 禁止把反光画成两条细短斜线，或形成眼睛、八字眉、眉毛、瞳孔、嘴及任何表情。
- 芽仔在页面中很小时，把反光简化成同一受光侧的一块短而宽的柔和弧面；不得简化成圆点，也不得完全删除反光。
- 芽仔的情绪只通过身体倾斜、手势、动作线和情境物件表达，不通过面罩图案表达。

## 纸蓝系统中的表现

- 身体是暖白纸面填色，外轮廓是略有抖动、偶有断点和二次描线的深墨手绘线。
- 芽仔可有浅薄剪纸层次和接触阴影，但纸纹、颗粒和阴影必须与周围物件一致。
- 三种模式只改变角色尺寸和细节简化程度，不改变材质；禁止光滑 3D、塑料玩偶、白棚商品照、厚重体积光和高光渲染。
- 不得变成人类、普通机器人、毛绒玩具、黑豆角色或带五官的卡通人物。

## 动作

芽仔必须操作关键关系：拉、挡、推、接、插入、连接、切换、检查、修复、比较或沿路径移动。遮住芽仔后信息仍能理解，但关键动作应明显失去引导。

默认只出现一个芽仔。只有时间线或连续阶段确实需要时，才允许同一个芽仔在不同节点重复出现。

## 比例

- 场景隐喻：通常占画面高度 12%–22%。
- 知识图解：通常占视觉重量 10%–18%。
- 信息可视化：通常占页面视觉重量 8%–18%，不能遮挡文本和路径。

## 身份修复顺序

出现漂移时只编辑芽仔，并按顺序恢复：面罩形状与单侧连续弧形反光 → 双叶绿芽 → 红臂带 → 灰腿带 → 胸前白/蓝/红按钮 → 圆手套和圆头靴 → 与场景一致的纸纹、墨线和浅阴影。保留文字、结构、比例和画幅不变。
